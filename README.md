# flexbox-use-to-create-amazon-webpage-basic-layout
**📦 Amazon-Style Navbar UI (HTML + CSS)**
This project is a basic front-end layout inspired by Amazon’s navigation bar. I built this to practice structuring web pages and styling responsive navbars using pure HTML and CSS — no frameworks, no JavaScript, just clean fundamentals.

**🔍 What’s Included?**
Fully structured navbar with:
A logo placeholder using background-image
Location selector box
Search bar with placeholder text
Sign-in and Cart sections
Flexbox-based layout for even spacing and alignment
Clean, minimal styling with reusable CSS classes
Beginner-friendly code structure that’s easy to expand

**🎯 What I Practiced**
Flexbox (aligning items, spacing, responsiveness)
Styling form elements like input bars
Using background images for logos
Building clean and organized HTML structure
Creating a consistent UI layout

**🚀 Why This Repo Exists**
This is one of my early web dev practice projects. I’m learning how real websites structure their UI, and this navbar is my first step toward building more advanced layouts and eventually full websites.
Feel free to explore, modify, or use this as a base if you’re also learning front-end.
