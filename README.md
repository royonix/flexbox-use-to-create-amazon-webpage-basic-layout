#flexbox-use-to-create-amazon-webpage-basic-layout

## **🛒 Amazon-Style Navbar UI (HTML + CSS)**

- This project is a basic front-end layout inspired by Amazon’s navigation bar.
+ Built to practice structuring web pages and styling navbars using pure HTML + CSS (no frameworks).

## **🔍 What’s Included**

- Fully structured navbar
+ Logo placeholder using background-image
* Location selector
^ Search bar with placeholder text
* Sign-in and Cart button
+ Flexbox layout for spacing + alignment
- Clean + beginner-friendly code structure

## **🧪 What I Practiced**
 
+ Flexbox (alignment, spacing, responsiveness)
- Styling input boxes
^ Using background images for UI
* Organized HTML structure
+ Clean, consistent UI layout

## **🌱 Why This Repo Exists**

  This is one of my early web development practice projects.\
  I’m learning how real websites structure their UI, and this navbar is my first step toward building better layouts and full websites.

## **🎯 Project Goal**

  This mini-project is part of my learning journey as I explore web development.\
  The focus here is understanding how real e-commerce websites design their navigation bars and recreating them using only HTML and CSS.
